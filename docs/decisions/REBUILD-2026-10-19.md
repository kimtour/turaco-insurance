## Architecture decisions

1. **Agent placement.** Deep Agents only proposes partner column mappings. It receives schema metadata, never raw records, credentials, financial tools or database access. Deterministic mock inference remains the default.
2. **Workflow durability.** Spring Boot/PostgreSQL owns billing stages, review decisions and invoice preparation. The model is not the state machine. Existing LangGraph conversation persistence remains in place.
3. **Billing authority.** Java validates every row and calculates decimal totals. An authorized human approves a batch. A unique partner/period invoice preparation and transactional locks prevent duplicates. All invoices are simulated.
4. **Completeness.** Requirements are versioned and effective-dated. September historical demo claims retain their original behavior; new requirements apply to later Hospital Cash incidents. Uploading is distinct from reviewer verification. Wrong associations and stale fact digests cannot satisfy requirements.
5. **Model boundary.** Bedrock requires explicit enablement, region and model allowlisting. Mock CI never needs credentials. No region/model availability is inferred. Model failures route to review.
6. **Delivery.** Add migrations and small modules; retain the existing claims/payout paths. Future notification and voice work is simulator-only. Official integrations and production hosting require actual contracts, account configuration and evaluation evidence.
